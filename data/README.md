# 가이드 문서 (RAG 지식 베이스)

`search_guides` 도구가 검색하는 문서다. 파일 하나가 주제 하나이고, `## ` 제목 하나가 검색 단위(조각) 하나다.
이 README는 검색 대상에서 빠진다.

- 수치는 두 종류다. **시뮬레이터 규칙**은 `src/web/static/index.html`의 `renderChecks`에 들어 있는 점검 기준과 같은 값이고,
  **일반 권장**은 흔히 알려진 사무 환경 요령이다. 둘 다 공인 기준을 인용하거나 의학적으로 검증한 것이 아니다.
- 점검 규칙을 바꾸면 이 문서도 함께 고친다(문서와 점검 결과가 다르면 에이전트가 서로 다른 말을 하게 된다).
